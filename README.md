# vdoxxy — портфоліо

Односторінковий сайт-портфоліо українською. Чистий HTML, CSS і JavaScript —
без збірки, залежностей і фреймворків. Готовий до GitHub Pages.

## Файли

```
index.html      — весь вміст і тексти
styles.css      — оформлення (кольори у :root на початку файлу)
script.js       — меню, поява блоків, активний пункт навігації
favicon.svg     — іконка сайту
assets/avatar.jpg — аватар
```

## Контент

Зараз на сайті:

- **vdoxxy** — вайбкодер та інді-розробник;
- Python, Java, C++, Unity, Blender;
- досвід — 3 місяці;
- два моди для Minecraft (другий — проти затримки Mace у PvP);
- перша гра в процесі: карта, анімація персонажів, моделі в Blender;
- посилання на GitHub і Modrinth.

Формулювання навмисно обережні: «вивчаю основи», «розбираюся»,
«намагаюся робити». Коли з'явиться більше впевненості й готових
робіт — тексти й статуси в стеку варто уточнити.

Коли з'являться публічні репозиторії або релізи на Modrinth — додайте
прямі посилання в картки `.mod` та `.link-card` у секції `id="work"`.

## Що легко змінити

| Що | Де |
| --- | --- |
| Ім'я / нік | `vdoxxy` в `index.html` |

## Локальний перегляд

Достатньо відкрити `index.html` у браузері. Або:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публікація на GitHub Pages

Сайт опублікований: **https://vdoxxy.github.io/**

Репозиторій: `vdoxxy.github.io` (гілка `main`, папка `/`).

Оновлення після будь-яких змін:

```bash
git add .
git commit -m "Опис змін"
git push
```

GitHub Pages перебудує сайт автоматично за 1–2 хвилини.

Якщо колись доведеться розгортати з нуля: створіть **публічний**
репозиторій `vdoxxy.github.io`, завантажте файли в `main`, потім
**Settings → Pages → Deploy from a branch → main → / (root)**.

> Важливо: репозиторій має бути публічним — GitHub Pages на приватних
> репозиторіях доступний лише на платному плані.

## Власний домен (необов'язково)

**Settings → Pages → Custom domain**, вкажіть домен і додайте у DNS
CNAME-запис на `vdoxxy.github.io`. Файл `CNAME` створиться автоматично.

## Примітки

- Файл `.nojekyll` уже доданий.
- Сайт повністю статичний: швидко, безкоштовно, без сервера.
